# v0.1.0-pre.5候補ノート（未公開）

English: [v0.1.0-pre.5-candidate.md](v0.1.0-pre.5-candidate.md)

これは[#321](https://github.com/albert-einshutoin/qzt/issues/321)で扱う未公開候補です。
現行の[Install](../../README.ja.md#install)とツアーは、検証済みの**公開pre.3**
を使います。別の公開と公開asset検証が完了するまで、pre.5のRelease URLを
導入先にしません。最終merge後の候補source SHA、native/globalのrun、hash、
artifact期限は#321へ記録します。

## pre.4からpre.5へ進む理由

[pre.4候補](v0.1.0-pre.4-candidate.ja.md)はsource
`4715196614c54c54b7809f99a422343ef2cf7b85`で未公開検証を通過しました。
annotated tagはそのSHAを指したままです。tag-onlyの[公開run 36257908117
attempt 1](https://github.com/albert-einshutoin/qzt/actions/runs/36257908117)
では4 native成果物のビルド後、rootの未追跡`dist-manifest.json`を
ビルド環境照合が拒否しました。global buildと保護されたhostingは実行されず、
**pre.4のReleaseは公開されていません**。tagと失敗runを履歴として保持し、
#320は公開完了ではなくnot plannedとして閉じました。

pre.5には#27のn-gram posting昇順vector化と#316のCompactV2 file-backed
QZI open改善を引き継ぎます。pre.4以降の製品差分はCLI配布版と、native/globalの
tag-only公開workflow修正および必要な検証・文書の整合です。QZTは`qzt-0.1`、
QZIはv1/v2で、公開API、検索field、`qzt-attestation-v1`は変えません。
公開判断前に実際のpre.4→pre.5 Git差分を確認します。

[#27](../benchmarks/2026-09-issue27-ngram-build.md)と
[#316](../benchmarks/2026-09-issue316-token-open.md)の性能値は、Apple M4/macOSの
固定合成入力で、OS cacheを制御せず開発binaryを測ったものです。
**pre.5候補binaryの性能測定値ではありません**。公開binary、Linux/Windows、
実ログ、並行検索、固定RSS上限、本番SLAの値も示しません。

## 公開経路リハーサルと候補証拠

生成された[tag-only公開workflow](../../.github/workflows/release.yml)は
source clean検査を維持し、native/globalのraw manifestを無視対象の
`target/release-workflow/`に書きます。read-onlyの
[候補workflow](../../.github/workflows/release-candidate.yml)と公開workflowは
同じ[build/manifest script](../../scripts/release-workflow-build.sh)を使います。
候補workflowは各nativeとglobalのビルド環境を記録し、実際の`dist build`、
ビルド後照合、manifest読込・copy、artifact upload/download、4 native成果物を
受けたglobalのchecksum/installer生成、hostの内部JSON除外後のファイル集合を
検証します。hosting API、保護された`release` environment、tag/Release作成、
公開URLからのinstallは**実行しません**。

macOS ARM64/Intel、Linux x64、Windows x64ではarchive/sidecar/展開binaryの
hash、version、必要なlinkage、固定smokeを記録します。globalはsource archiveの
全file内容・実行bitを選択Git treeと照合し、5つのaggregate checksum、
installerのversion URL、予定asset集合を確認します。
[小さい互換性fixture](../../scripts/verify-pre4-compatibility.py)は公開pre.3と
選択したpre.5 binaryのQZT/QZI読込み・検索、Deep verify/export、canonical
attestation byteを比較します。artifactは期限付きなので、以前のrunから期間を
推測せず、#321へAPIの`expires_at`を記録します。

公開は別判断です。受入済み候補の正確なSHAへ新しいannotated pre.5 tagを
作り、保護されたtag-only workflowを使用します。
