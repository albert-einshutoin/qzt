Candidate and public archives are distinct builds. Archive hashes differ; Windows
binary hashes also differ. Binary build reproducibility is not claimed. Published
source/run identity and actual artifact/installed byte identity were verified.
On macOS ARM64 the generated installer reported skipping its own sha256 check
because `sha256sum` was unavailable. The verifier independently checked the
public archive digest/sidecar before execution and installed binary equality.
The README recommends manual checksum-before-extraction using `shasum` on macOS.

Success covers these exact assets and bounded fixtures. It does not establish
exhaustive search coverage, external provenance, independent real-data adoption,
GB/TB safety, resource/performance limits, all future versions or codec support.
Format/schema/public API and product implementation were unchanged; v0.1 remains
zstd-only. External Validation, G3/G4 and broader G5 remain outside M1.
